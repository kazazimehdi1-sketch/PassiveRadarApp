# فلزیاب راداری منفعل 📡

برنامه اندروید هوشمند برای تشخیص فلزات و مواد باستانی با استفاده از راداری منفعل و AI

## ✨ ویژگی‌ها

- 📡 **تحلیل صوتی پیشرفته**: بررسی فرکانس‌های بالا تا 192 کیلوهرتز
- 🤖 **الگوریتم‌های AI**: Entropy، Dielectric، Fractal Analysis
- 📍 **موقعیت‌یابی دقیق**: GPS و سنسورهای دستگاه
- 📸 **ثبت بصری**: دوربین برای مستندسازی
- 📊 **داده‌های سنسور**: شتاب‌سنج، قطب‌نما، دما، فشار، رطوبت
- 💾 **ذخیره‌سازی آفلاین**: Room Database
- 🎯 **دقت بالا**: هماهنگ‌سازی تمام داده‌ها در لحظه

## 🛠️ فناوری‌های استفاده شده

- **Kotlin** - زبان برنامه‌نویسی
- **Jetpack Compose** - UI
- **Room** - پایگاه داده
- **Coroutines** - برنامه‌نویسی async
- **Google Play Services** - موقعیت‌یابی و نقشه
- **CameraX** - دوربین

## 📋 نیازمندی‌ها

- Android 7.0+ (API 24)
- GPS فعال
- دسترسی به میکروفن
- دسترسی به دوربین

## 🚀 شروع کار

1. Clone کنید:
```bash
git clone https://github.com/kazazimehdi1-sketch/PassiveRadarApp.git
cd PassiveRadarApp
```

2. Android Studio میں باز کنید

3. Gradle sync کنید

4. برنامه را اجرا کنید

## 📱 استفاده

1. **مجوزها**: تمام مجوزها را تایید کنید
2. **شروع**: دکمه ▶️ را فشار دهید
3. **منتظر بمانید**: سیستم در حال تجزیه و تحلیل است
4. **نتایج**: بررسی کنید:
   - نوع مادی
   - درصد دقت
   - موقعیت جغرافیایی

## 📊 تفسیر نتایج

| معیار | حد | توضیح |
|-------|-----|--------|
| Entropy | > 0.04 | پیچیدگی سیگنال |
| Dielectric | > 0.08 | تراکم مادی |
| Fractal | < 0.9 | ناهموار بودن |
| RMS | > 0.02 | قدرت سیگنال |
